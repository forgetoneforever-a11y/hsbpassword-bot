# Hsbpassword Bot

Telegram-бот для проверки паролей на утечки, генерации и оценки силы.

## Возможности

- 🔐 Проверка утечек через HIBP (k-Anonymity)
- ⏱ Оценка времени взлома
- 📊 Проверка на топ-1000 популярных паролей
- ⌨️ Детект клавиатурных паттернов (qwerty, йцукен)
- 🇷🇺 Предупреждение для паролей на кириллице
- ⚡ Генератор случайных паролей
- 🔑 Генератор фраз из слов

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Меню с кнопками |
| `/check <пароль>` | Проверить на утечки |
| `/gen [длина]` | Сгенерировать пароль (по умолчанию 20) |
| `/phrase` | Сгенерировать фразу из слов |
| `/help` | Справка |

Также можно просто отправить пароль текстом — бот проверит автоматически.

## Деплой на Render

### 1. Подготовка

- Создай бота через [@BotFather](https://t.me/BotFather) → получи токен
- Залей код в GitHub репозиторий

### 2. Render

1. [render.com](https://render.com) → **New +** → **Web Service**
2. Подключи репозиторий
3. Настройки:
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node index.js`
   - **Instance Type**: `Free`
4. **Environment Variables**:
   - `BOT_TOKEN` = токен от BotFather
5. **Create Web Service**

### 3. Проверка

Render автоматически подставит `RENDER_EXTERNAL_URL`, и бот настроит webhook.
